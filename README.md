# My Coffee App

A simple Android app built with Kotlin using Android Studio.

## Tech Stack

- **Language:** Kotlin
- **IDE:** Android Studio
- **Build system:** Gradle (Kotlin DSL)

## Getting Started

### Run locally

1. Clone the repository
```bash
   git clone https://github.com/anshupriya18052006/My_Coffee_App.git
```
2. Open the project in Android Studio and let Gradle sync finish.
3. Run the app on an emulator or a physical device.
